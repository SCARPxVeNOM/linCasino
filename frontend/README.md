# Casino Royale Frontend

A React-based frontend for the Linera Casino Platform, featuring Poker, Rummy, and Roulette games.

## Features

- 🃏 **Texas Hold'em Poker** - Play poker against AI opponents
- 🃎 **Rummy** - Match cards and form melds
- 🎲 **Roulette** - Spin the wheel and test your luck
- 💰 **Bankroll Management** - View and manage your balance
- 🎨 **Modern UI** - Beautiful, responsive design

## Setup

1. Install dependencies:
```bash
npm install
```

2. Build the frontend:
```bash
npm run build
```

3. The built files will be in the `dist/` directory, which can be served by the deployment script.

## Development

Run the development server:
```bash
npm run dev
```

The app will be available at `http://localhost:5173`

## Configuration

The frontend requires a `config.json` file in the public directory with the following structure:

```json
{
  "nodeServiceURL": "http://localhost:8081",
  "pokerAppId": "...",
  "rummyAppId": "...",
  "rouletteAppId": "...",
  "bankrollAppId": "...",
  "defaultChain": "...",
  "userChain1": "...",
  ...
}
```

This file is automatically generated by the `run.bash` deployment script.

## Usage

1. **Select a Game**: Choose from Poker, Rummy, or Roulette from the main menu
2. **Start a Game**: Enter your name and click "Start Game"
3. **Get Balance**: Click "Refresh Balance" to update your account balance
4. **Play**: Use the game-specific actions to play

## Game Controls

### Poker
- **Bet**: Place a bet with a specific amount
- **Call**: Match the current bet
- **Raise**: Increase the bet
- **Fold**: Give up your hand

### Rummy
- **Draw from Deck**: Take a card from the deck
- **Draw from Discard**: Take the top card from the discard pile
- **Discard Card**: Click a card in your hand to discard it
- **Declare**: Declare your melds to win

### Roulette
- **Place Bet**: Select a bet type and amount, then place your bet
- **Spin**: Spin the wheel to see the result

## Architecture

- **React** - UI framework
- **Apollo Client** - GraphQL client for backend communication
- **TypeScript** - Type-safe development
- **Vite** - Build tool and dev server

## Components

- `CasinoRoyale` - Main component with game selection
- `PokerGame` - Poker game interface
- `RummyGame` - Rummy game interface
- `RouletteGame` - Roulette game interface

## Hooks

- `usePoker()` - Poker game state and actions
- `useRummy()` - Rummy game state and actions
- `useRoulette()` - Roulette game state and actions
